# Многопользовательская игра на Python

Это многопользовательская игра на Python с использованием Pygame для клиента и Go для сервера. Игра поддерживает несколько игроков на одной карте, с системой WebSocket для реального времени, AI для мобов, системой снарядов, чатом и админ-командами.

## Возможности

- **WebSocket-сервер на Go**: Реализация сервера с Gorilla WebSocket для обработки соединений.
- **Управление игроками**: Подключение/отключение игроков, движение, атака.
- **AI мобов**: Мобы движутся к ближайшим игрокам.
- **Система снарядов**: Выстрел, движение, столкновение с мобами.
- **Админ-команды**: /ban, /kick, /list, /stats, /help для администраторов.
- **Чат-система**: Общение между игроками и админ-команды.
- **Игровой цикл**: Трансляция состояния игры на 60 FPS.
- **JSON-сериализация**: С заглавными ключами (Players, Mobs, Projectiles).
- **Клиент на Python**: WebSocket-клиент с рендерингом Pygame и TMX-картой.
- **Простые квадраты для сущностей**: Зеленый для себя, синий для других игроков, красный для мобов, желтый для снарядов.
- **Ввод**: Движение стрелками, атака пробелом, чат клавишей T.
- **Камера**: Следит за игроком.
- **Чат-дисплей и ввод**: Показ последних сообщений.

## Установка

### Сервер (Go)
1. Установите Go (версия 1.16+).
2. Перейдите в папку `server`:
   ```bash
   cd server
   ```
3. Установите зависимости:
   ```bash
   go mod tidy
   ```

### Клиент (Python)
1. Установите Python (версия 3.7+).
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### Лаунчер
Лаунчер включен в клиентскую часть. Запускайте `launcher.py` для доступа к аккаунтам и обновлениям.

#### Запуск сервера обновлений
```bash
python update_server.py
```

Сервер обновлений запускается на порту 5000. Лаунчер проверяет обновления при запуске.

## Запуск

### Запуск сервера
```bash
cd server
go run main.go
```

Сервер запустится на порту 8080 (или PORT из переменной окружения).

### Запуск клиента
```bash
python main.py
```

Клиент автоматически подключится к серверу по умолчанию `wss://test-server-2zf4.onrender.com/ws`. Для локального сервера используйте `--server ws://localhost:8080/ws`.

Для оконного режима:
```bash
python main.py --windowed
```

## Развертывание

- **Тестирование локального соединения**: Запустите сервер и клиент локально.
- **Развертывание сервера**: На Render или Fly.io.
- **Обновление клиента**: Измените SERVER_URL в main.py на URL развернутого сервера.

## Тестирование

- **Запуск сервера локально**: `cd server && go run main.go`
- **Запуск клиента локально**: `python main.py`
- **Тестирование многопользователя**: Запустите несколько клиентов, проверьте движение, атаку мобов.
- **Тестирование чата и админ-команд**: Отправьте сообщения, используйте команды как админ.
- **Тестирование столкновений**: Проверьте обнаружение столкновений и респаун мобов.

## Устранение неполадок

1. Если клиент не может подключиться к серверу:
   - Убедитесь, что сервер запущен
   - Проверьте настройки файрвола
   - Проверьте, что URL сервера правильный

2. Если карта не загружается:
   - Убедитесь, что файл `maps/безымянный.tmx` существует
   - Проверьте, что библиотека pytmx установлена

3. Если спрайты не загружаются:
   - Убедитесь, что папка `sprites/` существует и содержит файлы
