# Многопользовательская игра с автоопределением сети

Это многопользовательская игра на Python с использованием Pygame и сетевого взаимодействия. Система автоматически определяет локальный IP-адрес и настраивает соединения между сервером и клиентами.

## Возможности

- **Автоопределение сети**: Автоматическое определение локального IP-адреса и доступных сетевых интерфейсов
- **Интерактивный ввод**: При запуске сервера можно выбрать IP-адрес вручную
- **Многопользовательский режим**: Поддержка нескольких игроков на одной карте
- **Расширенное логирование**: Подробное логирование событий сервера и клиентов
- **Гибкая конфигурация**: Настройки через JSON-файл
- **Поддержка TMX-карт**: Использование тайловых карт в формате TMX
- **Организованная структура**: Файлы отсортированы по тематическим папкам

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что у вас есть файлы:
   - `maps/безымянный.tmx` (карта в формате TMX)
   - `sprites/lena.jpg` (спрайт игрока)

## Запуск

### Запуск сервера
```bash
python server.py
```

При запуске сервер покажет все доступные IP-адреса и предложит выбрать один из них для прослушивания.

### Запуск клиента
```bash
python client.py
```

Клиент автоматически подключится к серверу, используя определенный адрес.

## Конфигурация

Настройки хранятся в файле `config/config.json`:

- `server`: Настройки сервера (хост, порт, максимальное количество игроков)
- `client`: Настройки клиента (адрес сервера, полноэкранный режим)
- `game`: Игровые настройки (размеры карты, скорость игрока)
- `logging`: Настройки логирования

## Управление

- **Стрелки**: Движение персонажа
- **ESC**: Выход из игры

## Логи

Логи сервера сохраняются в папке `logs/` с ротацией файлов.

## Устранение неполадок

1. Если клиент не может подключиться к серверу:
   - Убедитесь, что сервер запущен
   - Проверьте настройки файрвола
   - Проверьте, что IP-адрес определен правильно

2. Если карта не загружается:
   - Убедитесь, что файл `maps/безымянный.tmx` существует
   - Проверьте, что библиотека pytmx установлена

3. Если спрайт не загружается:
   - Убедитесь, что файл `sprites/lena.jpg` существует
