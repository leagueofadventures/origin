# 🎮 League of Adventures
> Многопользовательская 2D онлайн-игра с клиент-серверной архитектурой

## 📖 Описание проекта
Прототип многопользовательской онлайн-игры, разработанный для демонстрации реализации сетевого взаимодействия в реальном времени, управления игровым состоянием на стороне сервера и создания отзывчивого графического интерфейса. 

Сюжет повествует об одиноком путнике, который исследует мир, помогает страждущим и сражается со злом, скрывающимся в тёмных лесах и пещерах. Графика и окружение созданы с использованием нейросетевых сервисов (`Leonardo.Ai`, `Fusion Brain`), что позволило оптимизиров процесс разработки. Игровые карты реализованы в формате `.tmx`.

## 🏗 Архитектура
Проект разделён на три независимых модуля:
- **🚀 Лаунчер** — самостоятельное приложение для регистрации/входа, проверки обновлений, безопасной загрузки новых версий с прогресс-баром, передачи токена авторизации и запуска клиента с параметрами подключения.
- **🖥 Клиент** — игровое приложение на Python с поддержкой 2D-графики, анимаций, системы настроек и клиент-серверного взаимодействия через WebSocket.
- **🌐 Сервер** — высокопроизводительный бэкенд на Go, отвечающий за управление игровым состоянием, авторизацию, администрирование и раздачу обновлений.

## 🛠 Технологии
| Компонент | Стек и библиотеки |
|-----------|-------------------|
| **Сервер** | `Go`, `gorilla/websocket`, `PostgreSQL` |
| **Клиент** | `Python`, `Pygame`, `websocket`, `pytmx` |
| **Лаунчер & Админ-панель** | `Python`, `Tkinter` |
| **База данных** | `PostgreSQL` (хостинг: Render.com) |
| **Графика & Ассеты** | Нейросети: `Leonardo.Ai`, `Fusion Brain` |
